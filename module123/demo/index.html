PROBLEM & DIFFICULTY

生成一次内容并不难，
难点在于让全流程稳定运行。

论文来源、文件格式和平台接口各不相同。项目需要处理每个环节的输入输出，并保证流程可以重复执行。

01 / INPUT

最新论文如何筛得准？

关键词检索会产生大量弱相关结果，摘要还可能被截断。若直接交给模型逐篇判断，调用成本随候选数量增长，旧论文和重复论文也会反复消耗额度。

核心矛盾：信息新鲜度、相关性与筛选成本难以同时兼顾
02 / CONTENT

PDF 如何变成可信内容？

论文图表可能是整页图片、矢量元素或文字与线条组合，不能依赖“提取内嵌图片”。直接总结全文又容易引入噪声，让图文对应关系失真。

核心矛盾：结构理解、图表精确定位与内容忠实度
03 / DELIVERY

内容怎样真正进入发布流程？

Markdown、图片素材、微信 HTML、封面 media_id 和草稿接口具有不同的数据约束。生成后的文章还需要完成格式转换、素材上传和接口校验，才能进入发布流程。

核心矛盾：内容表达与平台工程约束之间存在断层
04 / RELIABILITY

多环节失败后如何定位和恢复？

检索、下载、解析、模型调用、生图和平台接口都可能独立失败。若只保留最终结果，任何异常都要从头重跑，也无法判断错误来源。

核心矛盾：流程越长，可观测性和可恢复性越重要
选题意义 01缓解论文增长与人工阅读时间之间的矛盾先由机器初筛，再由研究者深读，让更多时间用于分析和判断。
选题意义 02缩短学术成果从发现到传播的链路将总结、配图和排版纳入同一流程，降低重复制作成本。
选题意义 03提高 AI 生成内容的可检查性保留论文证据、图表来源和中间产物，支持人工复核。
选题意义 04验证 MCP 在跨工具协作中的工程价值编排层通过标准工具调用平台能力，减少对接口细节的耦合。

TECHNICAL INNOVATION

版面几何定位与证据约束生成，
共同降低图文错配

LAYOUT-AWARE EXTRACTION

版面感知图表提取

  1. 标题检测

    逐行识别 Figure、Fig.、Table 及编号，记录标题类型、页码与坐标。

  2. 候选区域生成

    Figure 搜索标题上方最近图片块；Table 搜索标题下方连续横线簇。

  3. 边界约束

    以下一图表标题、页面边缘和最大高度共同限制裁剪范围。

  4. 自适应回退

    缺少横线时，根据文本块间距、章节标题与正文特征推断表格结束位置。

  5. 质量校验

    过滤尺寸过小的区域，并以 2× 分辨率渲染为独立 PNG。

BOUNDARY RULE 图表结构特征 + 相邻内容边界 + 回退判定

创新定位 面向科研内容生产的系统方法创新

各模块以可检查的中间产物连接，确定性程序处理格式与约束，大模型负责语义判断和内容生成，最终形成可独立验证、局部重做的连续流水线。

01 / DECISION FUNNEL

通过分层筛选控制 LLM 调用范围

常见做法：抓到论文后逐篇调用模型判断。

本项目机制：月份过滤、本地去重、摘要补全先缩小候选集，再进行语义价值判断。

创新价值：把模型用在必须理解语义的环节，兼顾新鲜度、精度与调用成本。
02 / EVIDENCE GROUNDING

先构造证据包，再生成公众号内容

常见做法：仅凭标题和摘要一次性生成文章。

本项目机制：组合论文元数据、补全摘要、PDF 正文与图表清单，要求模型输出结构化章节和图片引用。

创新价值：生成过程由论文证据约束，降低内容空泛、图文错配和无依据扩写。
03 / GEOMETRY-AWARE CROP

基于版面几何关系提取论文图表

常见做法：提取 PDF 内嵌图片或按固定高度截图。

本项目机制：联合 Figure/Table 标题、图片块、表格横线和相邻标题边界计算裁剪区域。

创新价值：兼容图片、矢量表格等不同 PDF 结构，并减少正文和相邻图表混入。
04 / DECOUPLED COVER

把视觉生成与文字准确性解耦

常见做法：让生图模型直接生成含标题的完整封面。

本项目机制：模型只负责主题背景，准确标题、副标题和关键词由 Pillow 程序化排版。

创新价值：保留生成式视觉表现，同时避免中文乱码、错字和论文名称失真。
05 / ARTIFACT CONTRACT

用中间产物定义模块间数据契约

常见做法：函数间传递临时对象，失败后只能整体重跑。

本项目机制：以 JSON、Markdown、PNG、HTML 作为阶段输出，路径和元数据可被后续模块读取。

创新价值：模块可独立测试、替换和复用，错误也能定位到具体阶段。
06 / SAFE DELIVERY

将发布动作变成可预览的 MCP 能力

常见做法：业务脚本直接耦合微信上传和草稿接口。

本项目机制：封装预览、图片上传、草稿与发布工具，默认先生成本地 HTML 供人工确认。

创新价值：把不可逆发布变成受控步骤，并让同一能力可被不同编排器调用。
